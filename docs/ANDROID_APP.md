# แอป Android + พิมพ์ผ่าน Bluetooth

แอปตู้ Photobooth สำหรับโทรศัพท์/แท็บเล็ต Android ที่ใช้หน้าจอชุดเดียวกับตู้ Windows ทุกหน้า และพิมพ์ใบเสร็จ (thermal 58/80 มม.) ผ่าน Bluetooth หรือเครื่องพิมพ์ LAN

## แนวทาง: ระบบเดียว ไม่แยกเวอร์ชัน

- **หน้าเว็บ (UI ทุกหน้า) ใช้ชุดเดียวกัน** — `npm run build` ได้ `dist-next` แล้วแอป Android บรรจุไฟล์ชุดนั้นไว้ใน APK หน้าเว็บไม่ต้องแก้ ไม่มีโค้ดแยกสองชุดให้ดูแล
- **ส่วนที่ต่างกันมีแค่ "ตัวกลาง" (native bridge)** — Windows ใช้โปรแกรม `agent/` (Node) ส่วน Android ใช้แอปใน `android/` ทั้งสองให้ `window.PhotoboothDevice` / `window.PhotoboothPrinter` และเส้นทาง `/api/printers`, `/api/direct-print` แบบเดียวกันทุกเมธอด (ตามสัญญาใน `docs/REDEEM_NATIVE_BRIDGE.md`)
- สคริปต์ฝั่งหน้าเว็บของ Android คือ `clientScript` ตัวเดียวกับ Windows (`bridge/core.mjs`) ครอบด้วย `android/web/bridge-shim.js` ที่ส่งคำขอเข้าแอปแทนการยิง HTTP
- มีเทสต์กันหลุด: ถ้าเพิ่มเมธอดใน `bridge/core.mjs` แต่ลืมเพิ่มใน `DeviceApi.kt` เทสต์ `android/scripts/bridge-client.test.mjs` จะไม่ผ่าน
- ตู้ Windows เดิมไม่ได้รับผลกระทบ (ไม่ได้แก้ `agent/`, หน้าเว็บ หรือ Supabase)

```
หน้าเว็บ (dist-next ชุดเดียวกัน)
  ├─ Windows: Chrome kiosk → http://localhost:8787 → agent/server.mjs → Windows spooler (USB/LAN)
  └─ Android: WebView → https://appassets.androidplatform.net → Kiosk.kt → Bluetooth SPP / TCP 9100
                                    ↘ ทั้งสองเรียก Supabase Edge Functions ชุดเดียวกัน (credential อยู่ในตัวกลางเท่านั้น)
```

| อัปเดตอัตโนมัติ (ช่องทดลอง → เผยแพร่ แบบเดียวกับ Windows) | ✓ ติดตั้งเองตอนตู้ว่าง (ดูหัวข้อ "อัปเดตอัตโนมัติ") |

## Build APK

ต้องมี JDK 17 + Android SDK (platform 35, build-tools 35) ติดตั้งไว้ที่ `%LOCALAPPDATA%\pb-android-toolchain` แล้ว (หรือกำหนด `JAVA_HOME` / `ANDROID_HOME`)

```
npm run android:build
```

ได้ไฟล์ `dist-android\Photobooth-<เวอร์ชัน>-android.<commit>.apk` — สคริปต์ build หน้าเว็บแบบ production, คัดลอกเข้าแอป, ใส่ Supabase URL + publishable key (คีย์สาธารณะเท่านั้น), รัน unit test แล้วเซ็นชื่อ APK

**กุญแจเซ็นแอป**: build ครั้งแรกสร้าง `%USERPROFILE%\.photobooth\android-release.jks` และ `android-release.json` (รหัสผ่าน) — **ต้องสำรองไว้และห้าม commit** ถ้าหาย APK เวอร์ชันใหม่จะติดตั้งทับแอปเดิมไม่ได้ (ต้องถอนแอปแล้วตั้งค่าตู้ใหม่)

## ติดตั้งบนโทรศัพท์

1. คัดลอกไฟล์ `.apk` ลงโทรศัพท์ (สาย USB, Google Drive, LINE ฯลฯ) แล้วแตะเปิด
2. Android จะถามให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" จากแอปที่ใช้เปิดไฟล์ → อนุญาต → ติดตั้ง (Play Protect อาจเตือนเพราะไม่ได้มาจาก Play Store ให้กด "ติดตั้งต่อไป")
3. เปิดแอป **Photobooth** → อนุญาต **กล้อง** และ **อุปกรณ์ที่อยู่ใกล้เคียง** (Bluetooth)
4. จับคู่เครื่องพิมพ์: การตั้งค่า Android → Bluetooth → จับคู่อุปกรณ์ใหม่ → เลือกเครื่องพิมพ์ (PIN มักเป็น `0000` หรือ `1234`)
5. หน้า "ตั้งค่าตู้" ในแอป: กรอก Kiosk ID + Device credential (จาก `node scripts/create-kiosk.mjs --name "Booth 1"`), เลือกโหมด และเครื่องพิมพ์ → บันทึก

อุปกรณ์ที่รองรับ: Android 8.0 ขึ้นไป, Android System WebView เวอร์ชันใหม่ (อัปเดตจาก Play Store), แนะนำ RAM 4 GB+

เครื่องพิมพ์ที่รองรับ: เครื่องพิมพ์ใบเสร็จ Bluetooth แบบ **Classic (SPP)** ที่รับคำสั่ง ESC/POS (`GS v 0`) ขนาด 58 มม. (384 จุด) / 80 มม. (576 จุด) — ตั้ง "ขนาดกระดาษ" ในหน้าแอดมินให้ตรงกับเครื่อง; เครื่องพิมพ์ LAN ใส่เป็น `192.168.x.x:9100` ได้ (BLE-only ยังไม่รองรับ)

**ล็อกให้อยู่ในแอป (แนะนำสำหรับใช้งานจริง)**: การตั้งค่า → ความปลอดภัย → การปักหมุดแอป (App pinning) → เปิดแอป Photobooth → ภาพรวมแอป → ปักหมุด

**ตั้งค่าตู้ใหม่ / เปลี่ยน credential**: การตั้งค่า → แอป → Photobooth → พื้นที่เก็บข้อมูล → ล้างข้อมูล แล้วเปิดแอปใหม่

## อัปเดตอัตโนมัติ

ใช้ bucket `updates` และสองช่องเดียวกับ Windows แต่แยกไฟล์ไว้ที่ `updates/android/` (ไม่ชนกับของ Windows)

1. แก้โค้ด แล้วรัน `npm run android:publish` → build APK, อัปโหลดขึ้นช่อง **ทดลอง (canary)**
2. มือถือเครื่องหลัก (เลือกช่อง "ทดลอง" ตอนตั้งค่าตู้) ตรวจทุก 5 นาที ดาวน์โหลด แล้วติดตั้งเองตอนว่าง ทดลองใช้ให้แน่ใจ
3. พอใจแล้วรัน `npm run android:promote` → มือถือเครื่องอื่น (ช่อง "ปกติ") ทยอยอัปเดตตอนว่าง
4. ดูว่าแต่ละช่องอยู่เวอร์ชันไหน: `node android/scripts/publish-apk.mjs --status` (Dashboard เจ้าของแสดงเวอร์ชันที่ตู้รันอยู่)

- **ว่าง** = อยู่หน้าแรกไม่มีใครแตะ 20 วินาที หรือหน้าอื่นไม่มีการใช้งาน 10 นาที (ไม่ขัดจังหวะลูกค้า)
- **ความปลอดภัย**: แอปตรวจ sha256/ขนาด, ต้องเป็นแอปเดียวกัน เวอร์ชันใหม่กว่า และเซ็นด้วยกุญแจเดียวกับแอปที่ติดตั้งอยู่ (Android เองก็ปฏิเสธ APK ที่เซ็นด้วยกุญแจอื่น) — กุญแจ `android-release.jks` จึงเป็นตัวยืนยันว่าอัปเดตมาจากเจ้าของ
- **ครั้งแรก**: แอปเปิดหน้า "ติดตั้งแอปที่ไม่รู้จัก" ให้หนึ่งครั้ง ต้องเปิดอนุญาตให้ Photobooth แล้วกดย้อนกลับ (ไม่อนุญาต = อัปเดตไม่ได้ Dashboard จะแสดง error `update: ...`)
- **Android 12 ขึ้นไป** ติดตั้งเงียบไม่ต้องกดอะไร; Android 8–11 (หรือบางยี่ห้อ) จะขึ้นหน้าต่าง "อัปเดตแอปนี้?" ให้พนักงานกด **อัปเดต**
- **หลังอัปเดต** Android ปิดแอปเพื่อเปลี่ยนเวอร์ชัน: ถ้าตั้ง Photobooth เป็น **แอปหน้าหลัก (Home)** มือถือจะเปิดตู้กลับมาเอง (แนะนำ: กดปุ่ม Home → เลือก Photobooth → "ทุกครั้ง") ไม่อย่างนั้นแอปพยายามเปิดตัวเองกลับ แต่ Android บางรุ่นไม่ยอม ต้องแตะไอคอนเปิดเอง
- ติดตั้งไม่สำเร็จ 3 ครั้ง เวอร์ชันนั้นจะไม่ถูกลองอีก (รอเวอร์ชันถัดไป); ย้อนกลับเวอร์ชันอัตโนมัติแบบ Windows ทำไม่ได้บน Android จึงใช้ช่องทดลองกันไว้ก่อน
- เปลี่ยนช่องอัปเดตภายหลัง: ล้างข้อมูลแอปแล้วตั้งค่าตู้ใหม่

**มือถือที่ติดตั้ง APK รุ่นก่อนหน้านี้ (ยังไม่มีระบบอัปเดต) ต้องติดตั้ง APK รุ่นที่มีระบบอัปเดตทับด้วยมือหนึ่งครั้ง** หลังจากนั้นอัปเดตเองได้ ตู้ที่ตั้งค่าไว้ก่อนมีระบบนี้จะอยู่ช่อง "ปกติ"

## เช็กลิสต์ทดสอบก่อน deploy

**ติดตั้ง & ตั้งค่า**
- [ ] ติดตั้ง APK ได้, เปิดแล้วเห็นหน้า "ตั้งค่าตู้", ขอสิทธิ์กล้อง + Bluetooth
- [ ] รายชื่อเครื่องพิมพ์ Bluetooth ที่จับคู่แล้วขึ้นในหน้าตั้งค่า
- [ ] credential ผิด → ขึ้น "ระบบไม่ยอมรับ credential", ถูก → เข้าหน้าแรก
- [ ] ปิดแอปแล้วเปิดใหม่ ไม่ต้องตั้งค่าซ้ำ

**แอดมิน**
- [ ] เข้าแอดมินด้วย PIN ได้
- [ ] การเชื่อมต่อเครื่องพิมพ์ → เลือกเครื่องพิมพ์ Bluetooth จากรายการ → ทดสอบพิมพ์ ออกกระดาษ + ตัด
- [ ] ปรับความสว่างแล้วพิมพ์ทดสอบเทียบ
- [ ] สร้างโค้ด Redeem แล้วพิมพ์ (แต่ละใบตัดแยก)
- [ ] สลับโหมด Event ↔ Redeem

**ลูกค้า (โหมด Redeem)**
- [ ] กรอกโค้ด → เลือกเลย์เอาต์ → ถ่ายรูป (กล้องขึ้น, นับถอยหลัง, เลนส์) → เลือกธีม → พิมพ์ จำนวนใบตรงตามแพ็กเกจ
- [ ] ยอดคงเหลือของโค้ดลดลงถูกต้อง, QR ดาวน์โหลดรูป/GIF เปิดบนมือถืออีกเครื่องได้
- [ ] PromptPay (ถ้าเปิดใช้): สแกนจ่าย → ได้สิทธิ์พิมพ์

**ลูกค้า (โหมด Event)**
- [ ] ถ่าย → พิมพ์ฟรีได้ทันที

**กรณีผิดปกติ (สำคัญกับการตัดสิทธิ์)**
- [ ] ปิดเครื่องพิมพ์/ปิด Bluetooth แล้วกดพิมพ์ → แจ้งพิมพ์ไม่สำเร็จ และ **สิทธิ์ไม่ถูกตัด**
- [ ] กระดาษหมดก่อนพิมพ์ → ไม่ตัดสิทธิ์ (เครื่องที่ตอบสถานะได้)
- [ ] ปิดเครื่องพิมพ์ระหว่างกำลังพิมพ์ → ขึ้นสถานะ "ไม่แน่ชัด" ให้พนักงานตรวจ ไม่พิมพ์ซ้ำเอง
- [ ] เน็ตหลุดหลังพิมพ์เสร็จ → เน็ตกลับมาแล้วยอดถูกรายงานเอง (ภายใน ~30 วินาที)
- [ ] หน้าจอไม่ดับตอนว่าง, กดปุ่ม Back ไม่ออกจากแอป
- [ ] Dashboard เจ้าของเห็นตู้ Android ออนไลน์ (เวอร์ชันลงท้าย `-android.<commit>`)

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `android/app/src/main/java/com/memories/photobooth/MainActivity.kt` | WebView เต็มจอ, สิทธิ์กล้อง/Bluetooth, เลือกไฟล์ (แอดมินอัปโหลด), เปิด `window.PBNative` ให้เฉพาะ origin ของแอป |
| `AssetServer.kt` | เสิร์ฟหน้าเว็บจาก APK และแทรก `/__bridge.js` ก่อนสคริปต์ของหน้า (เหมือน agent) |
| `Kiosk.kt` | เส้นทางเดียวกับ `agent/server.mjs`, เมธอดแอดมิน/เครื่องพิมพ์, หน้าตั้งค่าครั้งแรก, heartbeat |
| `DeviceApi.kt` | พอร์ตจาก `bridge/core.mjs` เรียก Edge Functions ด้วย device credential |
| `PrintService.kt`, `PrintJournal.kt` | พอร์ตจาก `agent/print-pass.mjs`, `agent/jobs.mjs` (บันทึกงานก่อนพิมพ์ กันพิมพ์ซ้ำ, retry รายงาน) |
| `EscPos.kt`, `ReceiptImage.kt` | แปลงภาพเป็น ESC/POS raster แบบเดียวกับ `agent/escpos-raw.cs` |
| `PrinterLink.kt` | ส่งไบต์ไปเครื่องพิมพ์ Bluetooth SPP / TCP, ตรวจกระดาษ/ฝา, รอเครื่องพิมพ์รับครบก่อนตัดการเชื่อมต่อ |
| `Updater.kt` | อัปเดตตัวเอง: อ่าน `updates/android/<ช่อง>.json`, ดาวน์โหลด, ตรวจ, ติดตั้งตอนว่าง, เปิดแอปกลับหลังอัปเดต |
| `KioskConfig.kt` | ค่าตั้งตู้; credential เข้ารหัสด้วยกุญแจใน Android Keystore |
| `android/web/bridge-shim.js`, `setup.html` | สคริปต์หน้าเว็บฝั่ง Android และหน้าตั้งค่าครั้งแรก |
| `android/scripts/*.mjs` | build APK, เผยแพร่อัปเดต (`publish-apk.mjs`), คัดลอกหน้าเว็บเข้าแอป, เทสต์ bridge |

## งานถัดไป (ยังไม่ทำในรอบนี้)

- เครื่องพิมพ์ Bluetooth Low Energy (BLE-only)
- โหมด Device Owner (ล็อกตู้เต็มรูปแบบ, เปิดเองหลังรีบูต)
